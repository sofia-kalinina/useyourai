# Exercise formats

The only formats allowed. The learner sees only `question`; `expected_answer` is for the checker.

## Every question

- Holds everything needed to answer: one short instruction, then the target-language text, then any options or base form.
- Instructions, labels and glosses are in the interface language. Nothing else outside the target-language text.
- All target-language text is correct, except the one planted error in error correction.
- No notes or hints after the text, and nothing that names the rule being tested.
- At most one gloss, for a hard word outside the grammar point, from the target language into the interface language: `(Schlüssel = key)`.

## Formats

| Format | Levels | `question` | `expected_answer` |
|---|---|---|---|
| Word bank | A1–B1 | Text with a gap, then 3–4 options | The option |
| Open gap | A2–C2 | Text with a gap; a length limit is allowed | The word or form |
| Form the word | A1–C1 | Text with a gap, base form in brackets after it. For two-form topics (aspect, ser/estar), give one base form | The form |
| Pick one of two | A1–C2 | Text with a gap and `(A / B)`. Both options make sense alone; the context decides | The option |
| Translate into the target language | A1–B2 | One short sentence in the interface language. Only if it differs from the target language | The translation / accepted variants |
| Fix the error | A2–C2 | One sentence with one error in the target grammar, wrong in every register | The corrected sentence |
| Rewrite with a key word | B1–C2 | A sentence, a key word in capitals, same meaning required | The rewrite / accepted variants |
| Build the word | B2–C2 | Text with a gap, stem in capitals | The word |
| Change the register | B2–C2 | One sentence and the register to rewrite it in | The rewrite / accepted variants |
| Choose the nuance | C1–C2 | Text with a gap and 2–3 options, all grammatical; meaning or tone decides | The option — reason in at most five words |
| Complete the dialogue | A1–B2 | Two or three lines, one of them a gap | The line / accepted variants |

## Never

- Translating from the target language: the learner may not understand the sentence.
- Open writing ("write a sentence about…", "finish the sentence") or explaining a rule in words: the checker can't grade it reliably.
- More than one task in a question.
